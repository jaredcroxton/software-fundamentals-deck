06 · F-01 · Shared Design Concept

Grill me.

The design concept is invisible. Until you and the AI share it, you are building two different things.

# grill-me Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one by one.

40 questions. 60 questions. Sometimes 100. The AI becomes an adversary, pinging ideas back until alignment is real, not assumed. Better than default plan mode, which is too eager to ship an asset.

10 · F-04 · Architecture

Deep modules win.

Few large modules. Simple interfaces. Hidden complexity. AI navigates better. Tests get cleaner. Boundaries stop entropy.

Anti-pattern
Shallow modules
Many tiny blobs. Complex interfaces. AI gets lost walking the graph.
Pattern
Deep modules
Functionality hidden behind a simple interface. Test at the edge. Trust the inside.

11 · F-05 · Save Your Brain

Design the interface.
Delegate the implementation.

You own this
The boundary.
The interface. The contract. The shape of the edge. The test that verifies it. The purpose of the module.
AI handles this
The grey box.
What goes inside. The implementation details that don't change the contract. Treat it as opaque, verify from outside.

Caveat: not for finance. Not for security boundaries. For the 80% of modules where correctness is verifiable from the outside, this is how you stop drowning.

14 · Fundamentals in Practice

B.L.A.S.T.
The same shape, formalised.

A protocol for building deterministic, self-healing automation. Memory before tools. Schema before code. SOPs before implementation. Reliability beats speed.

B
Blueprint
Five discovery questions. Lock the JSON schema. Research existing patterns.
L
Link
Verify every API key. Handshake scripts pass. Stop if any link is broken.
A
Architect
3 layers. Architecture SOPs. Navigation logic. Atomic Python tools.
S
Stylize
Refine the payload. Pull design from the awesome-design-md library. Iterate.
T
Trigger
Cron. Webhooks. Listeners. Maintenance log written in claude.md.
15 · Pre-flight Discipline

No code
until the gates pass.

BLAST refuses to write Python until memory is scaffolded, schema is locked, and architecture exists. The same fundamentals from the talk, encoded as a runtime check.

Memory before tools
  • claude.md exists, schema locked
  • task_plan.md with phase checklist
  • findings.md with research log
  • progress.md tracking errors and tests
Architecture before code
  • Five discovery questions answered
  • API credentials verified, .env handshake green
  • SOP written for every tool in /architecture
  • Self-annealing repair loop wired in

If any box is empty, halt. The pre-flight is the equivalent of the grilling skill: the AI is not allowed to start until it has reached a shared design concept with you.

16 · Same Shape · Different Output
